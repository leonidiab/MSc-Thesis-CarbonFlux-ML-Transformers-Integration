Carbon Flux Behaviour
Classification System

This dashboard provides an interactive interface for the NEE (Net Ecosystem Exchange) state-change classification framework. The system leverages both classical machine learning (XGBoost) and modern transformer architectures (FT-Transformer, TabTransformer) to classify whether an ecosystem is functioning as a carbon sink or non-sink, based on satellite remote sensing and meteorological observations from Australian flux tower sites.

🛰️ 5 Australian Flux Tower Sites
📊 28 Input Features (MODIS + BOM)
🧠 3 Model Architectures
Sink (S) Ecosystem absorbs more CO₂ than it releases
Non-Sink (NS) Ecosystem releases more CO₂ than it absorbs
